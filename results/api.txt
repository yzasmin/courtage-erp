4. Refus metier, et format unique des reponses d'erreur
====================================================================================================

  resilier un devis : il n'a jamais pris effet, il n'y a rien a resilier
      POST /api/v1/contrats/SC-2026-00037/resiliation
      -> 409  code « transition_interdite »
         passage de devis a resilie refuse : les seules suites possibles de devis sont ['en_cours']

  resilier sans motif : le motif est obligatoire
      POST /api/v1/contrats/SI-2023-00002/resiliation
      -> 422  code « requete_invalide »
         motif : Field required

  saisir un avenant anterieur au dernier avenant du contrat
      POST /api/v1/contrats/SI-2023-00002/avenants
      -> 409  code « date_avenant_incoherente »
         la date d'effet 01/01/2020 precede celle du dernier avenant (01/09/2026, rang 6)

  contrat inconnu
      GET /api/v1/contrats/XX-9999-99999
      -> 404  code « contrat_introuvable »
         aucun contrat ne porte le numero XX-9999-99999

  adherent inconnu
      GET /api/v1/adherents/A000000
      -> 404  code « adherent_introuvable »
         aucun adherent ne porte le numero A000000

  produit inconnu
      GET /api/v1/produits/ZZ-INEXISTANT/delegation
      -> 404  code « produit_introuvable »
         aucun produit ne porte le code ZZ-INEXISTANT

  etat a une date anterieure au contrat
      GET /api/v1/contrats/SI-2023-00002/etat?a_la_date=2015-01-01
      -> 404  code « etat_introuvable »
         le contrat SI-2023-00002 n'existait pas le 01/01/2015 : il a ete souscrit le 17/11/2023

  souscrire pour un adherent inconnu
      POST /api/v1/contrats
      -> 422  code « reference_invalide »
         aucun adherent ne porte le numero A000000
