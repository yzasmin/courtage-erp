Dossiers pré-remplis à valider

File d'attente des dossiers extraits automatiquement de documents recus, avant toute ecriture definitive dans le portefeuille.

Écran en attente du module 4. L'agent de pre-remplissage lira les demandes de remboursement, les factures et les attestations recues, en extraira les champs, les confrontera au portefeuille, puis deposera ici un dossier au statut « a valider ». Cet ecran est le point de controle humain : rien n'est ecrit dans le portefeuille sans qu'un gestionnaire l'ait valide depuis cette page.

Aucun dossier en attente. Le module 4 n'est pas encore realise, donc aucun document n'a encore ete traite.

Ce que cet écran contrôlera

Les controles prevus avant qu'un dossier puisse etre propose a la validation, tels que la specification du module 4 les fixe :

  • l'adhérent et le contrat cités existent réellement dans le portefeuille ;
  • le nom lu sur le document se rapproche du nom de l'adhérent par similarité, et l'écart est affiché ;
  • les montants sont cohérents entre eux et avec la garantie invoquée ;
  • le contrat était bien en vigueur à la date des soins, ce que la reconstitution à date établit ;
  • la gestion des prestations est déléguée au cabinet sur ce produit, sinon le dossier est rejeté.
